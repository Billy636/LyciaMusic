# 数据目录与便携模式

Windows 便携版默认将应用数据保存到程序旁的 `data` 文件夹。复制整个软件文件夹时，请同时保留 `data` 和 `storage-location.json`。发布脚本会在便携 ZIP 中附带空文件 `portable`；旧便携版升级时，正式版程序所在目录没有 `uninstall.exe` 也会识别为便携版。安装版和开发模式保持原有系统数据目录，显式放置 `portable` 文件可以启用便携模式。

便携版首次启动会自动将原来系统目录中的数据迁移到 `data`，新目录成功打开并更新设置路径后清理原数据，不保留备份。已经使用便携目录的数据优先使用自身配置，不会再次导入其他系统配置。

## 自定义目录

在「设置 → 常规 → 存储空间 → 数据存放位置」选择空文件夹。确认后，可立即重启，也可稍后手动退出并重新打开；重启前仍使用当前目录，也可以取消待迁移操作。

下次启动在数据库、WebView 和应用窗口创建前复制数据，成功使用新目录后清理原数据：

- 包含媒体库数据库、设置、收藏、歌单、播放记录、窗口状态、导入字体、封面和头像、自定义背景缓存、远程音频缓存及 WebView 数据。
- 便携模式将 WebDAV 登录信息保存在本地数据库中，随数据一起迁移。数据目录包含敏感信息，请妥善保管；原有系统凭据不会自动删除。
- 用户选择的原始音乐、外部图片和视频仍留在原位置。复制便携版到其他电脑时，这些外部文件需要自行保留，并确保音乐目录可访问。
- 目标必须为空且可写，不能与当前任何数据目录相同、互为父子目录，或包含会导致递归复制的目录链接。
- 先复制到目标旁的临时目录，校验文件长度，完成后再切换。复制失败时继续使用原目录并显示原因，不覆盖目标目录中的其他文件，不删除原数据。
- 迁移中断后可再次启动重试；已完成复制但未提交目录设置的情况也可恢复。自定义数据盘不可用时会显示错误并停止启动，避免误建空白配置。
- 迁移和整体移动便携文件夹后，会更新数据库、设置中指向应用内部资源的路径。
- 原目录只清理本次已迁移且未发生变化的文件，不删除迁移后新增或修改的文件。占用或变化导致的清理失败会显示原因，并在下次启动重试。仅删除空目录，定位文件和无关文件保持原位。

安装版只在系统配置目录保留 `storage-location.json` 用于定位自定义数据。便携版将该定位文件放在程序旁，程序目录内的路径使用相对位置；若自定义到程序目录之外，移动软件后仍需要原自定义目录可访问。

迁移成功后不保留原数据备份；安装版原系统目录中的 `storage-location.json` 仍需保留，用于定位新目录。便携版迁移了原安装版配置时，也会更新该定位文件。
