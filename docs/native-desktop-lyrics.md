# Windows 原生桌面歌词

## 实现边界

Windows + Tauri 运行时的桌面歌词改用进程内 Rust / Win32 / DirectWrite / Direct2D；不创建 `desktop-lyrics` WebView。主界面、设置、托盘和播放器不变。浏览器预览以及非 Windows 平台仍沿用 Vue 桌面歌词实现。

入口：`src/features/desktopLyrics/native.ts`；数据桥：`src/composables/useDesktopLyricsWindowBridge.ts`；原生模块：`src-tauri/src/desktop_lyrics/`。

## 数据与生命周期

- 沿用现有歌词数据、设置字段、物理坐标持久化和 `desktop-lyrics:action` 事件。设置页不需要迁移用户配置。
- 完整状态在内容/设置变化时发送；播放时钟仍每 400ms 同步，暂停/恢复和主动 seek 立即同步。原生状态与时钟包共用递增序号并串行发送，旧包不会覆盖新状态；播放会话标识支持同曲重播/单曲循环重置。原生线程以单调时钟推进，普通后台负纠偏通过短暂减速或停留追赶，不把逐字高亮拉回；主动 seek 则按目标时间立即重锚。暂停冻结插值位置，恢复从新锚点计时，不累计暂停时长。新增协议字段为可选字段，兼容旧格式；逐帧绘制不经过前端 IPC。
- 一个专用线程拥有 HWND、COM、DirectWrite 排版和 Direct2D 资源。跨线程仅传递数据，WndProc 不借用渲染器，避免同步 Win32 回调的可变借用重入。
- 开关窗口串行化；关闭时销毁窗口、结束并 join 线程，释放 DC、DIB、画刷、排版和缓存位图。原生初始化失败不静默回退到 WebView，避免隐蔽恢复原来的内存开销。
- HWND 透明、无边框、不占任务栏、不主动夺取焦点。锁定后，鼠标进入整个歌词窗口范围即显示顶部中央解锁按钮；只在鼠标落到按钮本身时临时恢复鼠标交互，歌词正文及其他区域仍采用 `WS_EX_TRANSPARENT` 穿透。鼠标离开窗口后隐藏按钮。

## 迁移的交互与样式

- 按原顺序提供锁定/解锁、上一首、播放/暂停、下一首、关闭。
- 按原时间顺序选行，双行始终在第一行显示当前句、第二行预览下一句，每句切换后将下一句上移并更新预览；单行仅显示当前句。支持回退 seek、逐字时间和普通 LRC 的模拟逐字时间；seek 后直接显示对应的当前句及下一句，末句只显示当前句。
- 参考播放页，下一句之前至少 7 秒的前奏/间奏以三个点显示等待；显式空白 cue 也显示等待点。按源歌词结束时间或逐字结束时间判断，只有推定整行结束时间且没有源逐字时间的普通 LRC 不凭空推断演唱结束。等待点随媒体时间呼吸和填充，暂停时冻结；纯无歌词仍显示原有提示，曲末不生成虚假的等待下一句。间奏结束直接进入下一句，不让已唱完的旧句重新参与退场动画。
- 双行自然切句使用约 360ms 的三次缓出动画（先快后慢）：上一句上移淡出，预览句上移到第一行并逐步放大，新预览句从下方进入。翻译与罗马音随所属句组移动，正文区域裁剪不影响工具栏。动画使用缓存字形和独立的单调时钟，暂停后会完成已开始的动画；换歌、间奏、跳过多句、主动 seek、设置/尺寸/DPI 变化或隐藏恢复直接定位。
- 翻译、整行罗马音、逐词对齐罗马音、播放渐变色、封面 HSL 自动配色、自定义颜色、字体/导入字体、字号、行距、偏移、透明度、描边和两行独立阴影强度。
- 支持左/中/右与两端分离对齐、拖动、八方向缩放、边缘吸附、水平居中、位置记忆/重置、DPI 变化、移除显示器后恢复、置顶、全屏/暂停自动隐藏、悬停淡化。
- 拖动采用非模态鼠标捕获，拖动期间仍可继续时钟同步及绘制。

### 长句与窄窗口

Windows 原生歌词默认使用「设置 → 桌面歌词 → 长句处理 → 横向跟随」：

- 正文单行，最多因宽度缩小 15%；仍超宽时按逐字时间移动当前句，当前演唱位置保持在可见宽度约 60% 处。没有逐字时间或关闭逐字效果时，按整句时间推进；暂停冻结，seek 按新时间重定位。
- 左右边缘只在该侧仍有隐藏内容时渐隐。句首从左端开始，句尾停在右端；第二行预览的下一句保持句首，切换到该句时按当前播放时间开始跟随。
- 对齐罗马音与原词共同移动；独立罗马音、翻译预留各自行高，过长时也随主句进度移动。
- 双行仍表示两句歌词，不因长句增加正文行。窗口高度不足时，整个文字块统一缩小，保留所有已启用的辅助行；此时实际字号可能低于水平适配的 85% 下限，但不修改用户保存的字号。位置偏移也限制在可见区域内。
- 「自动换行」仍可选，每句正文最多两行，通过宽度/高度适配避免裁掉半行；该新选项仅对 Windows 原生渲染器生效。设置页静态样式预览不模拟横向移动。

原生文本并非 CSS 的逐像素复制：字体栅格化不同；描边使用 DirectWrite 字形轮廓与 Direct2D 圆角线条，阴影使用缓存的多点采样；换行、渐隐和背景效果也不等同于浏览器 CSS 动画。设置页的预览仍为 HTML/CSS，最终效果以实际原生歌词窗为准。

## 绘制策略

DirectWrite 排版与静态描边/阴影只在歌词行、尺寸、DPI 或设置变化时重建。逐词正文和逐词罗马音分别按实测 ascent/descent 共享基线，避免中文片段末尾空格或字体回退导致单字下沉。Direct2D DC render target 采用软件渲染，将预乘 BGRA DIB 经 `UpdateLayeredWindow` 合成到桌面；字形、描边和阴影按文本局部缓存，长文本拆成不超过 1024 物理像素宽的图块，避免超宽单张纹理。横向跟随只平移已有图块并更新填色，不逐帧重新排版或生成字形。

使用高精度 waitable timer 与窗口消息共同等待帧截止时间，普通播放目标 60fps，360ms 切句动画期间目标 120fps；不再每个消息重置 `WM_TIMER`。旧系统不支持高精度标志时使用普通 waitable timer。绘制时间计入帧预算，实际帧率受软件渲染耗时和显示器刷新率限制，未实测保证恒定 60/120fps。暂停动画收尾后/隐藏时不持续重绘，仅每 100ms 维护鼠标及显隐条件；不修改系统全局计时器分辨率。

逐字高亮使用按物理像素对齐的字形透明度遮罩；保留当前屏幕外的词，以便后续横向跟随显示。遮罩只在排版变化时生成，播放期间分别给互不重叠的左右区域填色；不再在浅色底字上叠画高亮字，避免浅色毛边、边缘透明度加厚和进度分界接缝。抗锯齿保留在遮罩里，`FillOpacityMask` 的 aliased 模式只作用于矩形裁剪，并非关闭文字抗锯齿。无需整窗超采样。

选择 DC render target 是为了透明分层窗口兼容性和较简单的资源生命周期，不宣称 GPU 零拷贝或一定降低 CPU。若后续性能实测需要，可在相同状态协议下迁移到 DirectComposition。

## 自动验证

```powershell
npm run build
npm test
cargo test --manifest-path src-tauri/Cargo.toml --lib -- --test-threads=1
```

原生测试使用真实隐藏 HWND、DirectWrite 和 Direct2D，检查透明预乘像素、逐字高亮变化、150% DPI 重绘、两端分离布局、私有字体集合、锁定命中测试/不激活窗口，以及 10 次渲染器创建/缩放/释放的 GDI 句柄回收。测试预览生成到系统临时目录 `lycia-native-lyrics-smoke.png`。这不是运行播放器的端到端桌面交互验收。

边缘回归测试覆盖 100%、125%、150%、200% DPI：检查纯红高亮没有残留绿色/蓝色分量，着色前后透明度不增加，部分高亮没有覆盖接缝。黑底预览生成到系统临时目录 `lycia-lyric-edge-100.png` 等文件。

窄窗口测试覆盖 520×160 逻辑像素、300% 字号、双行、翻译/罗马音、100%/150%/200% DPI、关闭逐字效果、暂停以及两种长句模式；检查每句、每条翻译在句首/中间/句尾均有可见像素，生成 `lycia-overflow-150-middle.png` 等测试图。

音频内核等模块正在修改时，可隔离运行同一份生产布局/渲染代码的测试：

```powershell
cargo test --offline --manifest-path scripts/native-lyrics-tests/Cargo.toml --target-dir src-tauri/target/native-lyrics-tests -- --test-threads=1
```

该验证入口不模拟播放器启动和 IPC 权限，不能替代完整应用的验收。

## 实机验收与内存比较

1. 使用重新编译的 Windows 程序，检查开启歌词没有新增歌词 WebView 渲染进程。
2. 同一曲目/歌词/设置，分别记录关闭、开启后稳定 30 秒、关闭后稳定 30 秒的整个播放器进程树内存。新窗口位于 Rust 主进程内，不能再只观察单个 WebView 进程。
3. 在相同的 release 构建条件下比较旧版与新版增量；不要把共享页重复相加，也不要把 debug/release、首次字体加载和稳定常驻内存混为一谈。
4. 连续开关 10 次、快速开关、暂停恢复、seek、切歌、空歌词/错误歌词、锁定穿透/解锁、托盘/快捷键，以及主窗口隐藏后播放。
5. 测试不同 DPI 双屏拖动、八方向缩放、显示器拔插、置顶与其他置顶窗口、全屏与暂停隐藏、导入字体、长歌词、翻译/罗马音及两端分离布局。

尚未给出播放器 release 版本的内存 A/B 实测结果；此前单个歌词 WebView 的 70–80 MB 不能直接当作已经节省的数值。
