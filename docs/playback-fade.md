# 播放淡入淡出

## 目标与交互

减轻播放、继续播放和暂停时声音突然变化带来的不适。

- 在「设置 → 音频输出 → 音频处理」提供「播放淡入淡出」开关，默认开启；旧配置自动补上默认值，用户选择随设置持久保存。
- 开始播放、切换到新歌曲、继续播放时，音量在约 300 ms 内从静音平滑升至用户设定值。
- 暂停时按钮立即切换状态，声音在约 300 ms 内平滑降至静音，再留出 80 ms 让音量平滑器与输出缓冲排空，随后真正暂停。
- 快速连续点击暂停、播放时，从当前渐变增益反向过渡；旧暂停不会在恢复播放后再次执行。
- 用户音量与渐变增益独立：过渡不移动音量滑块、不写入临时音量，也不解除静音。过渡期间调节音量仍然生效。
- 关闭开关后，后续播放、暂停使用直接切换。停止播放、清空队列等资源清理操作保持立即执行。

此功能只处理单首歌曲的播放状态切换，不混合两首歌，也不在自然结尾提前淡出，避免吞掉曲尾内容。

## 实现

前端在 `play_audio`、`pause_audio`、`resume_audio` 中传递 `fadeEnabled`，由音频工作线程统一执行；主界面、迷你播放器、托盘和媒体快捷键沿用同一播放入口。未携带参数的旧调用保持直接切换。

后端保留用户音量，向现有 `UserVolumeSource` 传递「用户音量 × 渐变增益」。增益使用 smoothstep 曲线，渐变期间每 10 ms 更新，继续经过已有的逐采样音量平滑器；共享输出和 WASAPI 独占输出使用同一控制逻辑。排空等待不阻塞命令接收，暂停期间的反向操作可以立即取消待执行暂停。

开始新歌曲、停止、拖动进度和切换输出设备或模式时取消旧渐变，按新的播放状态重置增益。暂停淡出期间音频位置自然前进；恢复播放时读取后端实际进度校准时间轴，并拒绝旧歌曲、旧播放意图或旧跳转对应的异步结果。

## 验收关注点

- 普通输出与独占输出下，首次播放、暂停、继续播放均有短暂平滑过渡。
- 快速执行「暂停 → 播放 → 暂停」，最后状态和实际声音一致。
- 淡出期间切歌、拖动进度、清空队列或切换输出设备，不会被旧渐变再次暂停。
- 过渡期间调整音量、设为静音，不会在结束时跳回旧音量。
- 关闭开关、重启应用后设置仍保留；ReplayGain 与均衡器可以同时使用。
