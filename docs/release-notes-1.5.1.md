# Lycia Player 1.5.1 更新日志

相较于 1.5.0，本次更新主要完善歌词展示、封面与背景效果，以及音乐库管理体验。

## 新增

- **竖排歌词**：新增竖排封面歌词布局，支持纵向逐字高亮动效。
- **歌词阅读与源码编辑**：新增歌词阅读预览和源码编辑面板，支持切换正文、翻译与罗马音显示，以及源码查找和替换。
- **重复歌曲管理**：工具箱新增重复歌曲扫描与整理入口，支持按歌名和歌手或文件名匹配，并可结合时长筛选；支持试听、移动或删除冗余文件，每组至少保留一个版本。
- **文件夹合并为专辑展示**：支持将文件夹及子文件夹中的歌曲在专辑页合并显示，不修改原有歌曲标签。
- **首页与导航自定义**：支持设置默认首页、调整侧边栏导航顺序。
- **封面样式与动效**：支持切换封面样式，首页与播放页的圆形封面支持旋转；播放页新增封面倾斜动效，并记住封面居中状态。
- **雾染背景**：新增随歌曲封面取色的雾染动态背景。
- **透明窗口材质**：新增透明材质，支持调整背景不透明度。
- **歌曲信息刷新**：支持自动同步外部修改的歌曲标签，歌曲信息面板新增手动刷新入口。
- **托盘播控开关**：托盘菜单新增任务栏播控开关。
- **底栏音频快捷开关**：新增 WASAPI 独占与音量平衡按钮，可拖动到底栏或收纳进“更多”菜单，开启时高亮显示，并与音频设置同步。
- **歌词模糊开关**：歌词样式面板支持开启或关闭 AMLL 横排与竖排歌词的模糊效果，调整立即生效并保存。

## 优化

- 优化桌面歌词切句动画与逐字同步表现。
- 优化流光色域背景动画，并增加高 GPU 占用提示。
- 改善专辑封面清晰度，同时控制图片内存占用。
- 降低目录刷新时歌曲元数据的常驻内存占用；主窗口隐藏时暂停封面与背景准备，减少后台资源消耗。
- 限制自定义背景处理任务，并及时淘汰过期请求，减少重复处理。
- 优化侧边栏拖动排序体验，整合界面与导航设置，精简显示选项与说明。
- 将歌手头像设置与歌单排序选项移至对应页面，精简音频输出设置布局。
- 统一设置控件、下拉框、分割线与均衡器的深浅色样式，调整底栏设置布局和图标。
- 播放统计中的播放分布改为最近七天每日播放时长。
- 改善任务栏播控悬停时的歌曲信息展示。
- 缩小横排与竖排选择按钮，采用图标与文字横向排列；歌词字号上限调整为 200%，桌面歌词同步采用该上限。
- 调整底栏右键菜单顺序，将“刷新歌曲信息”移至“查看歌曲信息”上方。

## 修复

- 修复 Mini 模式缩放时按钮与歌曲信息被裁切的问题。
- 修复任务栏播控拖动异常，以及末句歌词高亮被尾奏拉长的问题。
- 修复歌词间奏指示点未跟随对齐设置的问题。
- 修复文件夹刷新后未同步外部修改的歌曲标签的问题。
- 修复文件夹批量移动异常，以及拖动预览越界的问题。
- 修复批量模式滑动选择时误触发歌曲拖动的问题。
- 修复底栏右键操作误触发“更多”菜单的问题。
- 修复窗口材质切换异常，并完善选项中文显示。
- 修复专辑页艺人名称无法点击跳转到艺人页面的问题。
- 修正底栏歌曲信息显示选项的文案。
- 补充内联样式的内容安全策略配置，改善相关界面样式的兼容性。
