# Lycia Player 1.5.2 更新日志

相较于 1.5.1，本次更新新增歌手分类模式、播放页背景与歌词调节选项，完善任务栏播控和窗口显示体验。

## 新增

- **专辑艺术家模式**：歌手页面支持在歌曲艺术家与专辑艺术家之间切换，相关专辑、歌曲列表与导航同步采用当前模式。
- **播放页背景设置**：新增柔光流动与静态渐变背景，支持预设配色、跟随封面取色，以及柔光背景的慢速流动开关。
- **歌词细节调节**：支持独立调整播放页翻译字号，并调节横排、竖排歌词的模糊程度，调整可即时预览并保存。
- **任务栏播控自定义**：支持“歌名＋歌词”“双语歌词”和“仅歌词”显示模式，可设置封面形状与旋转、文字颜色、背景透明度、窗口宽度，以及位置锁定、向左偏移和贴左边缘；同时完善拖动和任务栏内显示的稳定性。
- **分场景封面形状**：取消“两个场景保持一致”后，主界面与播放页可分别选择方形或圆形封面，切换页面时平滑过渡；重新开启同步时以当前场景为准。

## 优化

- 重新整理歌词样式面板的分组与布局，改善面板展开、选项切换和滑块操作的动画表现。
- 流光背景改为跟随封面配色的柔光流动效果，改善浅色主题下的色彩与光晕层次。
- 自动更新提醒改为左上角滑入横幅，减少对当前操作的打断。
- 将播放设备、音频输出模式及播放行为选项集中到音频输出设置，并精简重复歌曲管理页的说明文案。

## 修复

- 修复桌面歌词在无边框全屏游戏中无法恢复置顶，以及切换全屏后不可见的问题。
- 修复窗口暗色样式影响背景与毛玻璃通透效果的问题，并限定失焦时保持窗口材质的适用范围。
- 修复发布版歌词源码编辑器只显示行号、不显示正文的问题。
- 修复开机自动运行设置未正确生效的问题。

## 下载版本说明

- **标准版（Standard）**：适合大多数用户，安装时检查并在需要时下载安装 WebView2 运行时。
- **免检查版（No WebView Check）**：跳过安装时的 WebView2 检查，适合已安装运行时的用户；运行播放器仍需要 WebView2。
- **便携版（Portable）**：ZIP 压缩包，解压即可运行，无需安装播放器；电脑仍需已安装 WebView2 运行时。
