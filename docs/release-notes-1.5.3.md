# Lycia Player 1.5.3 更新日志

相较于 1.5.2，本次更新新增音乐库扫描规则、桌面切歌提示与任务栏歌词选项，改善歌词滚动和设置页面的显示体验，并修复多项背景加载与窗口显示问题。

## 新增

- **桌面切歌提示**：切换歌曲时，可在桌面右下角显示封面、歌名和歌手，默认关闭。
- **音乐库扫描规则**：本地和 WebDAV 音乐库支持选择收录格式、排除子文件夹；本地音乐库支持设置是否读取 CUE。
- **任务栏歌词自定义**：新增“当前句＋下一句”双行显示，支持逐字效果开关、翻译跟随高亮及独立高亮颜色。
- **任务栏间奏提示**：长间奏期间显示渐进三点动效。

## 优化

- 优化任务栏歌词横向滚动，解除原有 30 帧限制，跟随屏幕刷新节奏更新，并统一双行歌词的上移动画。
- 精简任务栏播控设置，调整分组、间距和选项名称，子设置随逐字效果展开；默认背景透明度调整为 50%。
- 缩短桌面歌词的字体选择框，收紧下拉菜单尺寸与选项间距。
- 精简音乐库导入入口，统一通过已有文件夹旁的“扫描设置”调整扫描范围。
- 移除任务栏歌词中的“等待歌词”文字，减少突兀提示。

## 修复

- 修复编辑或切换自定义背景时可能闪退的问题。
- 修复从托盘恢复窗口后，自定义背景出现上下黑边的问题。
- 修复 Win11 亚克力背景下，从任务栏唤起窗口时可能只显示背景、不显示内容的问题。
- 修复 4K 全屏切歌时，柔光封面背景出现色块和闪烁的问题。
- 修复背景图片扩展名与实际格式不一致时无法加载的问题。
- 修复自定义视频背景的加载权限问题，并完善加载失败提示。
- 修复部分异常 CUE 导致扫描中断的问题，跳过异常文件并显示警告。
- 修复部分 WebDAV 根目录及同名子目录的路径解析问题。
- 修复扫描设置弹窗和字体菜单的主题配色，改善辅助文字、禁用选项及按钮的可读性。

## 下载版本说明

- **标准版（Standard）**：适合大多数用户，安装时检查并在需要时下载安装 WebView2 运行时。
- **免检查版（No WebView Check）**：跳过安装时的 WebView2 检查，适合已安装运行时的用户；运行播放器仍需要 WebView2。
- **便携版（Portable）**：ZIP 压缩包，解压即可运行，无需安装播放器；电脑仍需已安装 WebView2 运行时。
